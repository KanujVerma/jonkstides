# Jonkstides

A modern e-commerce storefront for sourcing high-quality research peptides, integrated with Square Catalog.

🔗 **Live Demo:** [https://jonkstides.vercel.app/](https://jonkstides.vercel.app/)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Environment Setup

To run this project locally, create a `.env.local` file in the root directory with the following variables:

```env
SQUARE_ACCESS_TOKEN=your_square_access_token
SQUARE_LOCATION_ID=your_square_location_id
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```
